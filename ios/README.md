# Noir Wallet на iPhone через xtool (без Mac и Xcode)

Это необязательная оболочка: приложение с обычным окном браузера внутри, которое открывает https://benjaminpt.github.io/wallet-/. Плюс: данные хранятся внутри приложения и не стираются Safari через неделю бездействия. Обновления сайта приходят сами.

**Не проверено:** Swift-код написан без запуска на устройстве. Если `xtool dev` выдаст ошибку, пришлите её текст.

## Что нужно
- Компьютер (Windows через WSL, Linux или Mac) и USB-кабель к iPhone.
- Apple ID. С бесплатным аккаунтом приложение живёт 7 дней, потом его нужно снова поставить командой `xtool dev` (данные при этом сохраняются, если не менять bundle ID). С платным ($99 в год) срок год.
- На iPhone: Настройки → Конфиденциальность и безопасность → Режим разработчика → включить.

## Шаги
1. Установите xtool по инструкции https://github.com/xtool-org/xtool (раздел Installation для вашей ОС), затем один раз `xtool setup` (войдёт в Apple ID и скачает SDK).
2. `xtool new Noir` и перейдите в папку `Noir`.
3. Замените содержимое файла приложения в `Sources/` на `ios/Sources/NoirApp.swift` из этого репозитория (удалите остальные .swift-файлы шаблона с `@main`).
4. В `xtool.yml` задайте уникальный `bundleID`, например `com.ваше-имя.noirwallet`.
5. Подключите iPhone кабелем, разблокируйте и нажмите «Доверять». Выполните `xtool dev`.
6. Первый запуск: Настройки → Основные → VPN и управление устройством → доверять вашему Apple ID.

## Ограничения
- Вход по Face ID (WebAuthn) внутри такой оболочки, скорее всего, не заработает: для него нужна привязка к домену, которой у sideload-приложения нет. Для Face ID используйте установленный через Safari значок «На экран Домой». Нативный мост к Face ID можно добавить отдельно.
- Виджеты и Dynamic Island xtool не поддерживает.
- Данные установленного значка (Safari) и этой оболочки раздельны. Перенос: резервная копия в Настройках, затем «Войти → Восстановить из резервной копии».
