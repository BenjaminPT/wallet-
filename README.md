# Noir Wallet

Некастодиальный кошелёк: Ethereum и L2 (Base, Arbitrum, Optimism, Polygon, BNB), Bitcoin, Solana, TON, Tron. Работает в браузере как PWA, ставится на экран телефона, открывается как Telegram Mini App. Без KYC, без регистрации, ключи не покидают устройство.

> ⚠️ Кошелёк не проходил независимый аудит. Начните с **демо-режима**, затем с небольших сумм и тестовых сетей. Seed-фраза — единственный способ восстановить доступ.

## Как запустить

### Вариант 1. Ссылка на сайт (проще всего)
Сайт публикуется на GitHub Pages: `https://<ваш-логин>.github.io/noir-wallet/`
- **iPhone:** Safari → «Поделиться» → «На экран Домой».
- **Android:** Chrome → меню → «Установить приложение».
- **ПК/Mac:** Chrome/Edge → значок установки в адресной строке.

### Вариант 2. Архив: запускается на вашем ПК/Mac как сервер
1. Распакуйте `noir-wallet.zip`.
2. Windows: двойной клик `start.bat`. macOS: `start.command` (первый раз правый клик → «Открыть»). Linux: `./start.sh`.
3. Откроется `http://localhost:8080`. Пока устройство включено и окно не закрыто, кошелёк доступен.
4. Нужен Node.js 18+ ([nodejs.org](https://nodejs.org)). Без него `start.bat` откроет автономный `app/single.html`.

**Доступ с телефона:** кошельку нужен HTTPS (иначе браузер блокирует шифрование). Запустите `tunnel.bat` / `tunnel.sh` (Cloudflare, бесплатно, без аккаунта) и откройте выданную ссылку `https://….trycloudflare.com`. Ссылка меняется при каждом запуске, а данные кошелька хранятся в браузере для конкретного адреса, поэтому для постоянного использования ставьте кошелёк как PWA с вариантом 1 или с постоянным туннелем.

Docker: `docker build -t noir . && docker run -p 8080:8080 noir`

### Telegram Mini App
1. Создайте бота у @BotFather (`/newbot`).
2. `BOT_TOKEN=... node telegram/setup-bot.mjs https://<ваш-логин>.github.io/noir-wallet/`
3. В боте появится кнопка «Кошелёк».

## Безопасность
- Seed шифруется AES-GCM-256, ключ из пароля через PBKDF2-SHA256 (600 000 итераций), хранится в localStorage. Пароль не восстанавливается.
- Расшифрованная фраза живёт только в памяти, автоблокировка настраивается.
- Данные запрашиваются напрямую из публичных RPC/API (publicnode, Blockstream, toncenter, trongrid, CoinGecko, LI.FI, Jupiter). Они видят ваш IP и адреса.
- Обмен и стейкинг используют сторонние протоколы (LI.FI, Jupiter, Lido). Проверяйте суммы перед подтверждением.

## Что реализовано и ограничения
- Создание/импорт seed, проверка записи, пароль, автоблокировка, адресная книга, свои токены.
- Баланс, график, история (BTC/SOL/TON/TRX; для EVM ссылка на обозреватель), отправка (нативные + USDT/USDC), QR-приём и сканирование.
- Обмен: EVM-сети и кросс-чейн (LI.FI), Solana (Jupiter). Стейкинг: ETH через Lido. NFT: Ethereum через ключ Alchemy.
- TON: только нативный TON; адрес выводится из BIP39-фразы (SLIP-10), а не из родной 24-словной TON-фразы, поэтому не совпадёт с Tonkeeper.
- Биометрия не реализована (веб-версия): защита паролем и автоблокировка.
- Публичные RPC могут ограничивать запросы; при сбоях подставляйте свои RPC в `src/core/assets.js`.

## Разработка
```
npm install
npm test        # векторы адресов, шифрование
npm run build   # dist/ + dist/single.html
npm run serve
```
