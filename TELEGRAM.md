# Noir Wallet как Telegram-бот (Mini App): пошаговый гайд

Кошелёк уже лежит на GitHub Pages: **https://benjaminpt.github.io/wallet-/**
Telegram Mini App — это тот же сайт, открытый внутри Telegram. Свой сервер для бота **не нужен**.

## Что понадобится
- Аккаунт Telegram.
- Ссылка на сайт (HTTPS): `https://benjaminpt.github.io/wallet-/` (после включения Pages: Settings → Pages → Source: GitHub Actions).

## Способ 1. Только через @BotFather (без компьютера, 3 минуты)
1. Откройте в Telegram **@BotFather** → `/newbot` → введите имя (например `Noir Wallet`) → введите username, оканчивающийся на `bot` (например `noir_wallet_xyz_bot`). BotFather пришлёт **токен** вида `123456:ABC...` — **никому его не показывайте**.
2. Кнопка меню: `/mybots` → выберите бота → **Bot Settings** → **Menu Button** → **Configure menu button** → отправьте ссылку `https://benjaminpt.github.io/wallet-/` → отправьте название кнопки, например `Кошелёк`.
3. (По желанию) Отдельное Mini App со ссылкой `t.me/<бот>/app`: `/newapp` → выберите бота → название, описание → фото 640×360 (можно любое) → GIF пропустите `/empty` → вставьте ссылку на сайт → короткое имя (`app`).
4. Откройте своего бота → нажмите кнопку **«Кошелёк»** слева от поля ввода. Готово.

## Способ 2. Скриптом (то же самое, одной командой)
Нужен Node.js 18+.
```
BOT_TOKEN=123456:ABC... node telegram/setup-bot.mjs https://benjaminpt.github.io/wallet-/
```
(Windows, PowerShell: `$env:BOT_TOKEN="123456:ABC..."; node telegram/setup-bot.mjs https://benjaminpt.github.io/wallet-/`)

## Важно знать
- **Где хранятся ключи.** Зашифрованный seed лежит в хранилище встроенного браузера Telegram на этом устройстве. Если очистить кэш Telegram или удалить приложение, кошелёк пропадёт. Seed-фраза на бумаге — единственная страховка: импортируйте её в любой момент.
- **Разные устройства** — разные хранилища. На новом устройстве нажмите «Импортировать» и введите seed.
- **Бот ничего не знает о ваших ключах:** это обычный сайт, у бота нет серверной части и баз данных.
- **Пароль и seed не вводите в чатах и не пересылайте.**
- **Сканер QR** в некоторых версиях Telegram может не получить доступ к камере; тогда вставьте адрес вручную.
- Если меняете адрес сайта (например, перенесли на свой домен), повторите шаг 2 с новой ссылкой.

## Если что-то пошло не так
- Кнопка не появилась: полностью перезапустите Telegram.
- «Белый экран»: откройте ссылку обычным браузером; если там работает, обновите Telegram.
- Сайт открывается, но кошелёк «пустой» после обновления: это новое устройство или очищенный кэш — импортируйте seed.
