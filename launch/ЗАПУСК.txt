ЗАПУСК NOIR WALLET НА КОМПЬЮТЕРЕ (кратко)

0. Распакуйте архив ЦЕЛИКОМ (правый клик → «Извлечь всё»). Из окна архива не запускайте.

1. Установите Node.js (один раз): https://nodejs.org → кнопка LTS → установить → Далее, Далее.
   Проверка: откройте «Командную строку» и введите  node -v  — должна появиться версия (18 и выше).
   Без Node.js работает автономный файл app/single.html (двойной клик), но без режима сервера.

2. Запуск:
   • Windows: двойной клик по start.bat
   • macOS:   двойной клик по start.command
              (если macOS не даёт открыть: правый клик → «Открыть» → «Открыть»;
               если пишет «нет прав»: Терминал → chmod +x start.command)
   • Linux:   ./start.sh

3. Откроется браузер с адресом http://localhost:8080. Это и есть кошелёк.
   Чёрное окно НЕ закрывайте: пока оно открыто и компьютер включён, кошелёк работает как сервер.
   Если порт 8080 занят, сервер сам возьмёт 8081, 8082… (адрес покажет в окне).

4. Доступ с телефона (нужен HTTPS, иначе браузер блокирует шифрование):
   • Windows: откройте «Командную строку», введите  winget install Cloudflare.cloudflared
   • macOS:   Терминал →  brew install cloudflared
   • Оставьте start.bat запущенным, запустите tunnel.bat (или tunnel.sh) во втором окне.
   • В окне появится ссылка вида  https://слова-слова.trycloudflare.com  — откройте её на телефоне.
   ВАЖНО: ссылка меняется при каждом запуске, а данные кошелька хранятся в браузере для конкретной ссылки.
   Поэтому для постоянного использования на телефоне ставьте кошелёк как приложение по ссылке с GitHub Pages
   (https://benjaminpt.github.io/wallet-/ → «Добавить на экран «Домой»»), а компьютер используйте для себя.

5. Если что-то не запускается:
   • Окно закрывается сразу — запустите start.bat из «Командной строки» (cd в папку, потом start.bat) и посмотрите ошибку.
   • «node не найден» — установите Node.js (шаг 1) и перезагрузите компьютер.
   • Страница не открывается — откройте вручную http://localhost:8080 (порт смотрите в чёрном окне).
   • SEED-ФРАЗУ храните на бумаге: данные кошелька лежат в браузере и пропадут при очистке сайтов.
